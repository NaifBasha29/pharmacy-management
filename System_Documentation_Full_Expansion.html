4.1

Architecture Diagram

The system adheres to a highly decoupled **3-Tier Distributed Architecture**, leveraging the **MERN** application stack. This design ensures that administrative governance is separated from the operational concerns of clinics and patients, providing a single point of truth for auditing and data management.

Technical Stack Breakdown

  • Presentation Tier (React.js): A single-page application (SPA) that provides a responsive, state-driven interface. It utilizes Tailwind CSS for layout and Framer Motion for high-fidelity interactive elements.
  • Application Tier (Node.js & Express): A RESTful API gateway that handles complex business rules, role-based access control (RBAC), and session orchestration.
  • Data Tier (MongoDB): A document-oriented NoSQL database that offers horizontal scalability and schema flexibility for diverse pharmacy records.

Chapter 5: Testing and System Implementation

A robust system is only as good as its verification. The Super Admin module underwent exhaustive testing ranging from low-level unit checks to high-level stress simulations.

5.1 Quality Assurance Methodologies

  • Unit Testing (Jest): Focused on isolating utility functions such as the automated prescription number generator and password encryption salt variations.
  • Integration Testing (Supertest): Simulated API calls for the entire Clinic Enrollment life cycle, ensuring the database state remains consistent across multiple collection updates.
  • Security Boundary Tests: Manual and automated attempts to bypass JWT middleware using expired tokens or unauthorized roles (e.g., Patient attempting Admin routes).

5.3 Technical Implementation Workflow

The system implementation followed a **Blue-Green Deployment Strategy** to ensure zero downtime. The infrastructure was provisioned using environment-specific configurations.

Step-by-Step Installation Guide

1. CLONE REPOSITORY: git clone [remote-url]
2. CONFIG ENV: Create .env with MONGODB_URI and JWT_SECRET
3. INSTALL DEPS: npm install --prefix server && npm install --prefix client
4. SEED ADMIN: node server/utils/create-admin.js
5. LAUNCH: npm run dev

5.4 System Maintenance & Disaster Recovery

To maintain structural integrity, the system performs an automated "Cleanup" job every 24 hours that archives expired sessions and compresses Audit Logs older than 6 months into offline storage.

  • Daily Backups: MongoDB Atlas auto-backups every 6 hours.
  • Uptime Monitoring: Health checks via `/api/status` endpoint every 60 seconds.
  • Dependency Patches: Monthly security audit using `npm audit fix`.

The PharmaCare Super Admin Dashboard is a comprehensive solution for managing the complexities of modern pharmacy networks.
