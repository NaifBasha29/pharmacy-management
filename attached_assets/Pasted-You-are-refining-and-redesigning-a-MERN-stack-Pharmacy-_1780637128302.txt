## PHASE 1 — BACKEND FIXES

### 1.1 Global Error Handling
- Add a global error handler middleware in server.js / app.js:
  - Catch unhandled promise rejections
  - Return consistent JSON: { success: false, message: "...", error: "..." }
  - Never expose stack traces in production (check NODE_ENV)
- Add a 404 handler for undefined routes

### 1.2 MongoDB Atlas Connection
- In db.js or mongoose connect file, ensure:
  - mongoose.connect uses proper options: useNewUrlParser, useUnifiedTopology
  - Add connection error logging
  - Add retry logic on disconnect (mongoose reconnect on error event)
  - Wrap in try/catch and log meaningful errors

### 1.3 Auth Routes (/api/auth)
- Fix register: hash password with bcrypt before saving, return { success, token, user }
- Fix login: compare bcrypt hash, return JWT token + user object
- Fix /me route: verify JWT from Authorization header, return current user
- Fix forgot-password: generate OTP, store in user document with expiry (10 min), return success
- Fix verify-otp: compare OTP + check expiry, return reset token
- Fix reset-password: validate token, hash new password, clear OTP fields
- All responses must follow: { success: true/false, data: {}, message: "" }

### 1.4 Medicine Routes (/api/medicines)
- Fix GET /api/medicines: support query params: search, category, page, limit
  - Return: { success, data: { medicines, total, page, totalPages } }
- Fix GET /api/medicines/:id: populate category, return full medicine object
- Fix POST /api/medicines: validate required fields, return created medicine
- Fix PUT /api/medicines/:id: partial update support
- Fix DELETE /api/medicines/:id: soft delete (set isActive: false) or hard delete

### 1.5 Order Routes (/api/orders)
- Fix POST /api/orders: validate cart items, check stock, deduct stock on order creation
- Fix GET /api/orders: filter by user role (user sees own orders, pharmacist/admin sees all)
- Fix GET /api/orders/:id: populate medicines, user details
- Fix PUT /api/orders/:id/status: update status with timestamp, notify via response
- Fix order cancellation: restore stock on cancel

### 1.6 User Routes (/api/user)
- Fix GET /api/user/favorites: return populated medicine list
- Fix POST /api/user/favorites: add medicine to favorites array
- Fix DELETE /api/user/favorites/:id: remove from favorites
- Fix GET /api/user/home-medicines: return user's personal cabinet
- Fix POST /api/user/home-medicines: add entry with name, quantity, expiryDate
- Fix DELETE /api/user/home-medicines/:id: remove entry

### 1.7 AI Routes (/api/ai)
- Fix POST /api/ai/symptom-check: accept { symptoms } array/string, return conditions + suggested categories
- Fix GET /api/ai/recommendations: use user order history to return relevant medicines
- Fix POST /api/ai/chat: accept { message, history }, return { reply } string

### 1.8 Middleware
- Ensure auth middleware (protect) correctly:
  - Extracts Bearer token from Authorization header
  - Verifies JWT with correct secret
  - Attaches req.user to request
  - Returns 401 with { success: false, message: "Not authorized" } on failure
- Ensure role middleware (authorize) blocks wrong roles with 403

### 1.9 CORS
- In app.js/server.js, configure CORS to allow:
  - http://localhost:5173 (Vite dev)
  - Your production domain
  - Methods: GET, POST, PUT, DELETE, PATCH, OPTIONS
  - Headers: Content-Type, Authorization

## PHASE 3 — INTEGRATION & API WIRING

### 3.1 Axios Config (client/src/services/api.js)
- Set baseURL from import.meta.env.VITE_API_URL or fallback to http://localhost:5000/api
- Add request interceptor: attach Authorization: Bearer <token> from localStorage
- Add response interceptor:
  - On 401: clear token, redirect to /login
  - On any error: extract error.response.data.message for toast
  - Return response.data directly so callers get { success, data, message }

### 3.2 Auth State (AuthContext)
- On app load: call /api/auth/me to validate stored token
- Store: token, user object, isAuthenticated, isLoading
- Expose: login(), logout(), register() functions
- Handle token expiry gracefully

### 3.3 Cart State (CartContext)
- Persist cart to localStorage
- Expose: items, addToCart(), removeFromCart(), updateQuantity(), clearCart(), totalItems, totalPrice
